iframe sandbox 属性演示

sandbox属性用于对iframe内容施加额外的限制，提高安全性。不同的sandbox值提供不同级别的限制。

完全限制 - sandbox=""

<iframe src="..." sandbox>

最严格的限制：禁止脚本、禁止表单提交、禁止同源访问。

允许脚本 - sandbox="allow-scripts"

<iframe src="..." sandbox="allow-scripts">

允许执行JavaScript，但仍然禁止表单提交和同源访问。

允许脚本和表单 - sandbox="allow-scripts allow-forms"

<iframe src="..." sandbox="allow-scripts allow-forms">

允许脚本执行和表单提交，但仍然禁止同源访问。适用于大多数场景。

允许同源访问 - sandbox="allow-same-origin allow-scripts"

<iframe src="..." sandbox="allow-same-origin allow-scripts">

允许脚本执行和同源访问。仅当内容完全可信时使用此选项。

iframe 安全注意事项

1. 使用 sandbox 属性

始终使用sandbox属性来限制iframe内容的权限，仅开放必要的功能。

2. 设置 CSP 头部

使用Content-Security-Policy的frame-ancestors指令来控制哪些页面可以嵌入当前页面。

3. 避免嵌入不可信内容

不要在iframe中嵌入来源不可信的内容，这可能导致点击劫持等安全风险。

4. 使用 allow 属性

使用allow属性来精确控制iframe可以使用哪些Feature Policy，如autoplay、camera等。

allowfullscreenboolean是否允许全屏显示
loadinglazy/eager懒加载或立即加载

iframe allow 属性演示

allow属性控制iframe可以使用哪些浏览器功能：

允许自动播放

<iframe src="..." allow="autoplay">

允许摄像头和麦克风

<iframe src="..." allow="camera; microphone">
