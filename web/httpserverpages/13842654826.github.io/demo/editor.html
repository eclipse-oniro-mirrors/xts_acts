在线文档编辑器

欢迎使用在线文档编辑器！这是一个功能丰富的富文本编辑器，支持多种格式化操作和协作编辑功能。您可以使用上方工具栏来格式化文本、插入各种元素。

功能特性

  • 文本格式化：粗体、斜体、下划线、删除线、上标、下标
  • 字体样式：字体族选择、字号调节、字体颜色、背景高亮
  • 段落排版：标题层级、对齐方式、缩进控制、行距调节
  • 列表功能：有序列表、无序列表、多级嵌套
  • 插入元素：链接、图片、表格、代码块、引用、分割线
  • 编辑工具：撤销/重做、查找替换、清除格式
  • 文档管理：自动保存、历史版本、导出打印、全屏模式

编辑器功能

文本格式化

编辑器支持丰富的文本格式化选项。您可以选中文字后使用工具栏按钮进行格式设置。例如：粗体文字、斜体文字、下划线文字、删除线文字。

支持上标和下标：水的化学式是 H2O，数学公式 E=mc2。

字体颜色和背景高亮：红色文字、高亮标注。

插入功能

您可以插入各种内容元素，包括表格、代码块和引用。

示例表格

功能快捷键描述状态
粗体Ctrl+B将选中文字设为粗体已支持
斜体Ctrl+I将选中文字设为斜体已支持
下划线Ctrl+U为选中文字添加下划线已支持
撤销Ctrl+Z撤销上一步操作已支持
重做Ctrl+Y重做上一步撤销的操作已支持
查找Ctrl+H打开查找替换面板已支持

代码示例

编辑器支持代码块插入，方便展示代码片段：

function test() { return true; }

function greet(name) {
    return "Hello, " + name + "!";
}

const editor = document.getElementById('editor');
editor.addEventListener('input', function() {
    updateStats();
});

行内代码同样支持：document.getElementById('editor') 用于获取编辑器元素。
